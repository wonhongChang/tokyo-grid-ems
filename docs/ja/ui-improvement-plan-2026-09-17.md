## 使用率の出典

変更前の`web/src/App.tsx`の`peakUsageMetric()`は実績使用率を優先し、ない時間にはモデル需要 / TEPCO供給力を使っていました。最大値次第で出典が切り替わる一方、隣の需要カードはTEPCO予測でした。

9/17の公開画面点検時、17時89.7%はモデル34738.8MW / 供給力38710MWでした。同時刻のTEPCO予測33820MWなら約87.4%です。計算誤りではなく分子の出典が異なります。

推奨する表示契約:

- **最大実績使用率:** 有効な実測のみ。代替予測値を実績に含めません。
- **TEPCO予測最大使用率:** TEPCO需要 / 同時刻供給力。基本の予測指標にします。
- **モデル予測最大使用率:** モデル需要 / 同時刻供給力。補助指標として明示します。
- 供給力がどの使用率ピーク時刻に対応するかを示し、異なる時刻の需要・供給ピークを混ぜません。
- 供給力ゼロ・欠損やTEPCO予測欠損は欠損表示にし、出典を黙って切り替えません。

三言語で出典を明示します。92%・97%警告基準やモデル補正は変更しません。出典選択、欠損、同値、時刻対応、丸め境界をテストします。

## 検証画面の比較契約

`metrics/forecast_accuracy.json`には`latest_published_value_reference`、`tepcoSourceMayRevisePastValues: true`、`formalParityEligible: false`が記録されています。現在の「運用判断」は厳密な優劣判定と誤解されるため、**公開値ベースの誤差参考比較**に限定した表現にします。

既存の`metrics/forecast_vintage_accuracy.json`を別ビューで表示します。同じ`capturedAt`で取得した予測を正のleadで評価するもので、元の`issuedAt`はないため「同一発表時刻」とは呼びません。

推奨ビューは`事前予測比較` / `最新公開値の参考比較`。0〜2 / 2〜4 / 4〜8 / 8〜24時間、標本数、期間、モデル・方針範囲、標本不足を表示します。leadを無条件に合算せず、標本不足時に参考比較を正式評価として代用しません。

## MAE差の解釈

[公開値比較データ](https://wonhongchang.github.io/tokyo-grid-ems/metrics/forecast_accuracy.json)の取得時点の値です。公開データは後で変わることがあります。

| 範囲 | モデルMAE | TEPCO MAE | 絶対差 | 比率 | モデル / TEPCO WAPE |
|---|---:|---:|---:|---:|---:|
| 8/19〜9/17、713時間 | 605.9MW | 342.2MW | +263.7MW | 約1.77倍 | 1.86% / 1.05% |
| 完了した直近7日、9/10〜16、168時間 | 約502.0MW | 約232.7MW | 約+269.3MW | 約2.16倍 | 再集計なし |
| 9/15確定 | 673.2MW | 179.6MW | +493.6MW | 約3.75倍 | 2.06% / 0.55% |
| 9/16確定 | 498.1MW | 153.8MW | +344.3MW | 約3.24倍 | 1.65% / 0.51% |
| 9/17暫定、00〜16時 | 346.5MW | 237.6MW | +108.9MW | 約1.46倍 | 1.19% / 0.81% |

7日MAEは公開された日別MAEを時間数で加重した概算です。30日集計、14日グラフ、10日表は範囲が異なるため明示が必要です。

需要規模に対する平均絶対誤差が1〜2%台でも、TEPCO相当の性能とは言えません。直近日の相対差は実際に大きく、単なる見た目の問題ではありません。ただしTEPCOの過去値修正があり得るため、この表だけで事前予測の正確な性能差は確定できません。過去の同時取得スナップショットでも差が確認されており、すべてを表示や比較方法の問題として扱うことも不適切です。

表示改善:

1. 共通軸・ゼロ基準線・色を維持し、差を小さく見せるための軸拡張や二重軸を使いません。
2. MAE / WAPE切り替えを提供します。WAPEは同一標本の絶対誤差合計 / 実績合計で、日別率の単純平均ではありません。
3. ツールチップに両MAE、絶対差、両WAPE、標本数、集計中状態を表示します。倍率は補助とし、ゼロ分母は計算しません。
4. 単位は正しく、**1万kW = 10MW**、50万kWは約500MWです。現在はko/ja整数・en GW小数1桁に丸めるため、詳細には元のMW値も表示します。
5. WAPE 1.86%を「精度98.14%」と呼びません。平均、最大誤差、bias、時間差分の誤差を区別します。
