# 2026-09-04 v15候補スクリーニングレビュー

言語: [English](../../en/model-reviews/model-review-2026-09-04-v15-candidate-screening.md) / [한국어](../../ko/model-reviews/model-review-2026-09-04-v15-candidate-screening.md)

点検日: 2026-09-04 JST

根拠: `origin/data` commit `829497eab80fb92a8526ee39ef773b1bb3a21930`、2026-08-22〜09-02のv14-r2固定origin 12日、同期間のD0、2026-05-20〜08-21の開発区間

判定: **v15 q50の昇格を却下し、v14-r2を維持**

## 結論

最新データを追加した同一構造の再学習、lag重み、気象入力view、学習期間、origin専用直接モデル、residual stackingを順番に検証したが、開発区間と固定holdoutを同時に通過した候補はなかった。単一holdoutだけで改善した候補は、開発区間の悪化、区間回帰、またはbootstrap信頼区間が回帰を含むため却下した。

現行版の維持は作業を行わなかったという意味ではなく、同じ配布artifactと不変originで候補を落とした明示的な昇格判断である。q50の配信動作は変更しない。

## 基準線

| 評価 | 配布v14-r2 MAE | 同一構造の最新再学習 MAE | 候補の変化 |
|---|---:|---:|---:|
| D-1固定origin、12日 | 3,240.5MW | 3,407.3MW | 5.15%悪化 |
| D0、同一12日 | 約1,468.1MW | 1,484.2MW | 1.10%悪化 |

最新行を追加して現行構造を再学習するだけでは、最近のレジーム失敗を解消できなかった。

## 候補別結果

| 候補群 | 結果 | 却下理由 |
|---|---|---|
| lag/anchor設定 | D0最大改善0.46% | 改善が小さく日付bootstrap CIが1を超過。D-1 fallback無効化ではMAEが8,523.6MWに崩壊 |
| 気象source・humidity view | すべてD0基準線より悪化 | 入力削除では反復誤差を一般化して解決できない |
| 365/730/1,095日rolling学習 | D0 2.15〜9.44%、D-1 3.15〜5.59%悪化 | 新しいデータへの重み付けだけでは安定性が向上しない |
| origin-conditioned direct q50 | D-1 holdout 3.96%改善 | 開発区間3.45%悪化、最悪区間6.1%回帰、CI上限1.0295 |
| origin-conditioned residual stack | D0 holdout 1.81%改善 | 最悪区間16.66%回帰、CI上限1.1056。D-1は実質的に変化なし |

## 運用判断

1. v14-r2 q50モデルとartifactを維持する。
2. 個別失敗日のための時間固定capや新しいguardは追加しない。
3. P0証跡整合性修正で保存される不変D-1 originを継続して蓄積する。
4. 次のq50 Challengerはforecast vintageの気象lineageと新しいレジーム表現を確保してから設計し、根拠のない再学習は行わない。
5. 予測区間はq50と分離し、独立検証を通過したrolling conformal target政策だけを変更する。

## 残存リスク

- 不変D-1 holdoutは12日しかなく、モデル構造の昇格判断には短い。
- D0とD-1では利用可能な入力が異なり、同じ候補が逆方向の結果を示すことがある。
- TEPCOの最新値は過去予測が更新されるため昇格gateに使用しなかった。
- 実験artifactと一時データセットは配布repositoryに含めず、判断と再現可能な指標だけを記録する。
