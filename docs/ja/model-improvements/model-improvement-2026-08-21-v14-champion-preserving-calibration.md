# 2026-08-21 v14 Champion保持型キャリブレーション

言語: [English](../../en/model-improvements/model-improvement-2026-08-21-v14-champion-preserving-calibration.md) / [한국어](../../ko/model-improvements/model-improvement-2026-08-21-v14-champion-preserving-calibration.md)

## 判断

最初のv14案は時間別モデル全体を再学習し、独立D+1モデルを追加していました。この候補は配備前に棄却しました。運用v11比で当日営業日の11〜15時を平均約2.34GW引き上げ、翌非営業日を平均約3.25GW引き下げたため、意図した日次レベル補正だけでは説明できない大きな変化でした。

最終v14は運用v11のq025、q50、q975、lag-24 residual boosterをそのまま保持し、次の二つだけを追加します。

- 土日祝日に50:50で混合する非営業日専用q50
- 直近最大730完全日を学習し、日次レベル差の20%だけを+/-750MW以内で反映する日次レベルモデル

独立D+1モデルはありません。両方のv14補助経路は、前日24時間がすべて確定しているか、00〜22時が確定し23時だけがTEPCO予測fallbackの場合に限って作動します。それ以外の不完全なパターンではq50がv11契約と完全に同じになり、ほとんど未観測の当日を完全なlag日として扱いません。

TEPCO予測値は学習、補正、feature入力に使いません。fallbackは確定CSV実績が入るまでlag連続性だけを維持します。

## 同一cutoff replay

各holdout cutoffで両方とも同じv11時間別契約を再学習し、候補だけにv14補助モデルを追加しました。

| 期間 | v11 MAE / WAPE | v13参考 MAE / WAPE | v14 MAE / WAPE | v11比v14 MAE改善 |
|---|---:|---:|---:|---:|
| 28日 | 1245.8MW / 3.623% | 1183.5MW / 3.442% | 1142.5MW / 3.322% | 8.29% |
| 56日 | 1005.8MW / 2.995% | 975.6MW / 2.905% | 972.0MW / 2.894% | 3.36% |
| 84日 | 901.0MW / 2.852% | 884.1MW / 2.799% | 871.5MW / 2.758% | 3.27% |

28日営業日・非営業日MAEはそれぞれ7.61%、10.04%改善しました。深夜、朝、昼、夕方後半、夜はそれぞれ10.12%、9.05%、4.38%、9.75%、10.03%改善しました。全体shape-delta MAEは632.0から597.1MWへ低下しました。56日最大誤差は4.8MWだけ増え、28日と84日の最大誤差は減少しました。

性能低下Championの復旧基準は28日8%以上改善に加え、56/84日非退行、segment risk、最大誤差・shape、正確なartifact、smoke、drift gateをすべて通過する構造に変更しました。単一の10%閾値を越えるためにモデル強度を過剰調整しないためです。

## D+1安全性replay

frozen-origin欠損lag replayでは、当日が不完全なD+1絶対誤差は依然として大きい結果でした。したがってv14はD+1問題を解決したとは主張しません。安全契約は限定的です。前日観測が不完全なら新しい補助モデルは作動せず、v14固有ロジックによってv11より悪化しません。

最新`origin/data` cache基準で、2026-08-21と2026-08-22のstaging予測48時間は平均104.4MW、最大208.8MWだけ変化しました。今日は前日の確定実績23時間と許容した最後の1時間fallbackを使いました。前日coverageが不足した翌日はv11と完全に一致しました。

このstaging確認時点で確定していたのは00〜02時だけでした。3時間MAEはv11が162.7MW、v14が371.4MWで、24時間共通の+208.8MW shiftはこの区間では逆方向に働きました。部分日の結果を昇格指標には使いませんが、remote配備をoperator判断のままにし、確定日を安定化期間中に再確認すべき明示的な根拠です。この結果を受けて日次weightも0.25から0.20へ下げました。

## データcoverage監査

ローカルcacheには2023-01-01から現在の仮想予測範囲まで31,897時間行がありました。TEPCOとの差を説明し得る情報不足は次の通りです。

- 需要は1時間単位ですが、TEPCO AREAファイルには30分単位の需要・発電実績があります。
- 気象観測は東京AMeDAS 1地点で、首都圏の多地点気象場ではありません。
- 湿度、不快指数、気象source metadataは最近の運用期間だけ完全で、過去の大部分は欠損しています。
- 過去replayは最終観測気象を使い、当時の気象予報vintageを保持していません。
- 雲量、日射量、地域再エネ出力、産業稼働予定、event・系統運用入力がありません。

公式TEPCO AREA資料はfeatureではなく、固定day-ahead offline benchmarkとしてのみ使用しました。取得済みの全期間2025-09-01〜2026-08-19の353日ではTEPCO固定予測はMAE 347.8MW、WAPE 1.117%で、2026年のみの231日は369.9MWと1.188%でした。保存済み配信予測と一致する2,520時間ではTEPCO MAE 359.1MW、プロジェクトMAE 613.3MWでした。同一の予測商品ではありませんが、依然として有意な品質差があることを示します。

AREA実績から再エネlag feature 5個を追加する非公開実験も行いました。28日は改善しましたが56日・84日、特に夜が悪化したため採用しませんでした。

TEPCOの公開研究資料から、電力会社はより広域の気象、大規模気象データ、再エネ予測、細かな時間解像度を利用できると推測できます。これは公開資料に基づく推測であり、TEPCOの非公開運用featureを断定するものではありません。
