오늘 새벽 MAE는 85.8MW이다. 06~08시는 각각 599.4, 651.3, 842.0MW 과소예측했고, 11시는 1,104.5MW 과대예측했다. 12~14시 과대예측은 649.1, 776.2, 161.1MW이다. 전체 예측선을 일괄적으로 내리면 오전을 악화시킨다. 오늘 점심 dip은 존재한다. 11→12시 실측 하락은 1,000MW, 게시 예측선 하락은 1,455.4MW이다. 이것이 모든 점심 보정의 정확성을 보증하지는 않는다.

## 원형 모델 실험

v14-r2의 설정을 유지한 후보 하나를 **8월 28일 이전** 데이터로 재학습했다. **8월 28일~9월 10일**의 D0와 D-1 최초 입력을 나누어 실제 배포 가중치와 비교했다. 오늘의 날씨로 과거를 대체하지 않고 당시 Git 캐시를 사용했으며, 예측 대상일 실측을 가렸다. 현재의 결정적 피처·날씨 전처리는 두 모델에 동일하게 적용했다.

| Raw q50, horizon별 336시간 | D0 MAE | D-1 MAE |
|---|---:|---:|
| 배포 중 v14-r2 | 1,446.2MW | 2,658.1MW |
| 동일 구조 재학습 후보 | 1,513.7MW | 2,783.6MW |
| 배포 모델의 lag24 혼합 비중만 0으로 둔 제거 실험 | 1,550.4MW | 2,658.1MW |

이는 **최초 발행 입력에 대한 원형 모델 선별 실험**이며, 게시선 점수·전체 운영 replay·승격 판정이 아니다. Intraday와 D-1 일단위 보정도 포함하지 않았다. lag 제거 실험은 추론 설정만 바꿨으며 트리를 다시 학습하지 않았다. D-1 결과가 같은 것은 lag 결측 전용 모델을 사용하는 경로와 일치한다.

단순 재학습은 두 horizon 모두 약 4.7% 악화됐다. 승격하거나 v15로 이름을 바꾸지 않는다. lag24 혼합 제거도 D0를 악화시켜, lag24만 원인이라고 보고 없애는 방향은 지지되지 않는다. D-1 비영업일 원형 MAE 3,829.3MW는 다음 모델 설계 실험의 우선 과제이며, 받아들일 운영 목표가 아니다. 오늘 게시선이 나아졌다는 이유로 다음날 원형 모델까지 정상이라고 판단하면 안 된다.

### D-1 주말 전용 모델 분리 실험

lag가 없는 행에서 사용하는 공통 모델과 비영업일 전용 모델의 혼합 비중도 검사했다. 기존 비영업일 전용 비중 1.0과 후보 0.5, 0.0을 비교했다. **8월 14일~9월 10일, D0/D-1 각각 672시간**을 사용하고, 최근 2주와 그 앞 2주를 분리했다.

| D-1 비영업일 raw MAE | 기존 비중 1.0 | 후보 0.5 | 후보 0.0 |
|---|---:|---:|---:|
| 8월 14~27일 | 1,982.1 | 1,964.0 | 2,120.3MW |
| 8월 28일~9월 10일 | 3,829.3 | 3,347.4 | 2,868.0MW |
| 28일 합계 | 2,905.7 | 2,655.7 | 2,494.2MW |

최근 주말에는 전용 모델이 과대예측을 늘렸지만, 없애는 것이 항상 좋은 것은 아니었다. **8월 23일** MAE는 기존 596.2MW에서 0.5 후보 827.8MW, 0.0 후보 1,449.7MW로 악화됐다. 고정 비중 변경은 채택하지 않았다. 이는 최근 구간에 맞춘 일괄 하향의 위험을 보여주며, 가중치가 모든 오차의 원인이라는 뜻은 아니다.

기존 timeband/midday/local shape 후처리까지 적용한 D-1 전체 MAE도 28일 기준 3,096.3 / 3,024.5 / 2,978.4MW였다. **동일 영업 유형 일단위 학습 보정·Intraday 피드백·발행 이력 기반 밴드 보정·Freeze는 제외**했으므로 완전한 운영 replay가 아니다. D0는 세 후보 모두 동일했지만 이 672행에는 lag 결측 전용 경로가 켜진 행이 없었다. 따라서 실측 수집 장애가 있는 D0에도 무조건 안전하다고 해석할 수 없다.

과거 캐시에 기상 보정 근거가 없는 경우 새 API 값으로 채우지 않았다. 원천 캐시와 현행 전처리의 조합이라는 제한이 있으며, 앞선 2주도 과거 개발에 사용되었을 수 있어 독립적인 미사용 승격 holdout으로 주장하지 않는다. 다음 모델 실험은 단순 재학습·lag 제거·주말 전용 비중 일괄 축소를 반복하기보다 **발행 시점의 lag 가용성과 기상·수요 수준이 달라질 때 결측 전용 모델의 편향이 바뀌는 이유**를 대상으로 해야 한다.

## 채택한 보정 변경

[9월 10일 실측 지지 상한](model-improvement-2026-09-10-observed-support-floor.md)만으로는 완만하게 이어지는 하락을 해결하지 못했다. 어제 19:29 실행의 실측은 **33,250 → 32,900 → 32,740MW**였다. 마지막 -160MW만 보면 기존 단일 구간 기준 -500MW에 못 미치지만, 두 구간 합계는 -510MW이다. 이때 19·20시에서 각각 700MW가 복원되어 필요한 하방 보정을 되돌렸다.

기존 단일 구간 판정은 유지하고, 같은 음수 복원 레이어에 다음 대체 근거를 추가한다.

1. 연속된 진짜 실측 두 구간이 모두 하락하고, 합계가 기존 하락 기준(-500MW) 이하일 것.
2. 마지막 실측 다음부터 대상 시간까지 **모든 구간**의 lag24·최근 동일 영업 유형 delta가 모두 기존 지지 기준(-500MW) 이하일 것. 결측·비유한 값·약한 지지·중간 반등이 있으면 이 대체 조건은 작동하지 않는다.
3. 기존 복원 계수 **0.25**만 적용한다. 음수 잔차의 세기를 추가로 높이거나 raw q50를 변경하지 않는다. 음수 전용 조건, 실측 기준 1~2시간 리드, 기존 대상 시간, 복원 상한, 관측된 예측선 보존은 유지한다.

`negativeResidualNearTermDeclineEvidenceBasis`는 `latest_interval`, `two_interval_decline_with_supported_path`, 또는 복원 근거가 적용되지 않은 경우 null을 기록한다. 새로운 저녁 시각을 하드코딩하지 않았으며, 점심의 한 구간 dip을 지속적인 하락으로 취급하지 않는다.

## 제한된 검증

8월 29일~9월 11일의 보존된 calibration 실행 246개를 점검하고 Git blob 해시를 검증했다. 체크아웃 CRLF 정규화만 허용했다. 추가 조건에 해당한 것은 9월 10일 19·20시 두 행이다. 다른 단계의 문맥을 고정하고 기록된 cap을 재적용한 계산이며, **전체 피드백 궤적 replay는 아니다**.

| 대상 | 기존 규칙 계산 | 수정 계산 | 확정 실측 | 절대 오차, 전 → 후 |
|---|---:|---:|---:|---:|
| 19시, 발행 때 이미 시작된 구간 | 32,145.6 | 31,620.6 | 31,540 | 605.6 → 80.6MW |
| 20시, 구간 시작 전 발행 | 31,156.3 | 30,631.3 | 29,990 | 1,166.3 → 641.3MW |

복원량은 700→175MW이다. 19시 결과는 시작 전 예측 개선으로 집계하지 않는다. 효과 범위가 좁아 모델 전체의 정확도 개선을 입증하지 않는다. 운영 config를 사용한 전체 보정기 테스트에서 두 수정값과 최종 단계 합계를 재현하고, 관측 행·입력 객체·밴드의 상대 폭이 유지됨을 확인한다. 관측 공백, 단발 dip, 중간 반등, 약하거나 결측·비유한 지지, 양수 보정, 리드 범위 밖의 경우도 검사한다.

## Replay·운영 수정

외부 네트워크를 차단한 전체 테스트 **650개가 통과**했다. 오늘 16→17→18시 실측의 합계 -420MW에는 새 연속 하락 조건이 작동하지 않는 회귀 사례도 포함했다.

`fixed_origin_model_replay._origin_commit()`에 `git log --no-renames`를 적용했다. 보존 정책으로 파일이 교체될 때 Git이 새 타임스탬프 파일을 rename으로 판단하면, 기존 `--diff-filter=A`만으로는 9월 10일처럼 실제 D0 입력 커밋을 놓쳤다. 임시 저장소에서 교체 상황을 재현해 정확한 origin을 찾는 테스트를 추가했다. 과거 검증이 누락되거나 늦은 origin에 의존했다면 다시 확인해야 하며, 이 수정 자체가 특정 모델의 우수성을 입증하지 않는다.

ETL 로그는 **자동 후보 학습 비활성화**와 **예정 요일 아님**을 구분한다. 자동 후보 학습을 켜거나 승격 규칙·배포 가중치를 바꾸지 않았다.

`servingSemanticsVersion`은 **3**이다. 이전 정책 표본을 새 정책의 호환 밴드 근거로 섞지 않는다. 충분한 새 정책 근거가 쌓이기 전에는 기존 정규화·상한 처리를 거친 native 밴드를 유지한다. 오늘 게시 p95 포함률은 15/15, 평균 폭 4,578.3MW이고, 어제는 23/24, 5,070.0MW이다. 이 작은 표본만으로 95% 보정을 입증할 수 없으며, 이번에 폭을 임의로 줄이지 않았다.

## 남은 과제

- D0의 기온 하락일 수준 오차와 D-1 lag 결측 전용 모델을 분리해 검토한다. 단순 최신 재학습만으로는 해결되지 않았으며, 이번에 새 학습 모델을 승격하지 않았다.
- 오후 cap의 대상 시간·리드·마지막 실측 조건 경계는 남아 있다. 시간을 늘리면 단절 지점이 이동할 뿐 안전한 인계를 입증하지 못하므로 확장하지 않았다.
- 승격 실험에는 보정 피드백 궤적, D0/D-1, 평일·주말, 밴드와 독립 holdout이 필요하다. 이번 14일 기각 실험으로 대체하지 않는다.
- 배포가 별도로 승인된 뒤 일반 Intraday로 미관측 대상에 적용한다. 이미 관측된 예측선과 과거 성적을 다시 쓰지 않는다. 이번 점검에서 유료 OpenAI 호출·ETL 재실행·게시 데이터 교체는 하지 않았다.
