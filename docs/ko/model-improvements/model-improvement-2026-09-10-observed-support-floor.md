# 2026-09-10 음수 잔차 복원 하한의 실측 지지 범위 제한

언어: [English](../../en/model-improvements/model-improvement-2026-09-10-observed-support-floor.md) / [日本語](../../ja/model-improvements/model-improvement-2026-09-10-observed-support-floor.md)

## 진단

9월 10일 19:29 JST Pages 스냅샷에는 00~18시의 진짜 실측이 있으며, 게시 예측선 기준 MAE 957.4MW, WAPE 3.27%, bias +591.0MW입니다. 하루 전체가 아닌 부분 일간 평가입니다. 데이터 revision은 `165cc843d40f1c6f0cc02c568153d8239df284f4`입니다.

근거리 음수 잔차 하한이 과거의 높은 수요 수준을 근거로 최대 700MW를 복원하고 있었습니다. 이미 보정한 예측이 현재 실측보다 높은 경우에도 복원이 발생했습니다. 15:43 실행에서 마지막 실측은 33,400MW인데 15시 대상의 과거 기반 하한은 38,506.2MW였습니다.

```text
보정 전 35,672.1 - 잔차 보정 1,200 + 하한 복원 700
  - 오후 상한 보정 1,500 = 33,672.1 MW
```

하한 복원과 뒤의 상한 보정이 서로 반대로 작동한 것입니다. 이 충돌을 원래 예측 오차가 보존 정책 때문에 발생했다는 의미로 해석하면 안 됩니다. 실행별 재계산선과 게시 예측선은 구분하며, TEPCO 예측은 비교에만 사용합니다.

## 수정

`IntradayResidualCorrector._negative_residual_near_term_floor_restore()`에서 과거 기반 지지를 실측 수준으로 제한합니다. 상승이 확인되는 경우에만 제한적인 여유를 허용합니다.

```text
observed_base = 마지막 실측 - 기존 하락 허용폭
actual_floor = observed_base - actual_reference_slack

ramp_allowance = 기본 0
연속된 두 실측 기울기가 모두 양수이고
대상 시간의 lag24 변화량과 같은 영업 유형 변화량도 모두 양수이면:
    ramp_allowance = min(최근 실측 기울기, 두 실측 기울기의 평균,
                         대상 lag24 변화량, 대상 같은 영업 유형 변화량) * lead

historical_floor = min(최근 평균 - anchor_slack,
                       observed_base + ramp_allowance)
floor = max(actual_floor, historical_floor)
```

과거 평균이 없으면 실측 기반 하한을 유지합니다. 대상 변화량이 없거나 양수가 아니거나 앞선 실측이 누락되면 상승 여유만 꺼지고 실측 기반 보호는 남습니다. 과거 변화량이 아주 작은 양수라는 이유로 큰 상승을 허용하지 않습니다.

기존 음수 보정 전용 조건, 마지막 실측 기준 1~2시간 리드, 최대 700MW 복원, 최소 복원량과 하락 감쇠는 유지합니다. 복원량은 원래 음수 보정량을 넘지 않으므로 이 레이어가 보정 전 예측보다 더 올릴 수는 없습니다. 대상 시간도 늘리지 않았습니다. 복원 적용 시 `negativeResidualNearTermRampAllowanceMw`에 상승 여유를 기록하며, 미적용 시 null입니다.

## 저장 증거 검증

9월 5~10일의 104개 실행을 확인했습니다. 로컬 체크아웃에서 복사한 파일은 CRLF 정규화만 허용하여 고정 데이터 트리의 blob hash와 대조했습니다. 하한이 적용된 22개 행 중 4개는 하한이 그대로였고, 나머지 18개 행의 기존 복원량을 재현했으며 14개 행에서 복원량이 줄었습니다.

변경 행은 뒤에 기록된 오전/오후 상한과 설정된 차감 규칙까지 다시 계산했습니다. 이는 **같은 문맥을 고정한 하한·상한 단계 재현**이며 재학습이나 전체 파이프라인 반사실 replay가 아닙니다. 기록되지 않은 다른 단계의 신규 발동, 실행 간 피드백은 이 계산으로 검증되지 않습니다. 다음 표에서는 대상 시간 시작 후 갱신분을 제외하고, 같은 대상은 시작 전의 가장 가까운 발행본만 선택했습니다.

| 날짜 | 변경된 사전 발행 대상 수 | 기존 MAE | 후보 MAE | 개선 / 악화 / 동일 |
|---|---:|---:|---:|---:|
| 9월 5일 | 2 | 560.4MW | 332.8MW | 1 / 1 / 0 |
| 9월 10일 | 5 | 881.0MW | 559.6MW | 4 / 0 / 1 |

영향받는 일부 대상의 수치이며 **전체 일간 MAE 개선치가 아닙니다**. 보관된 9월 6~9일 실행에는 복원량 변화가 없었습니다.

악화 사례도 있습니다. 9월 5일 13시는 실측 30,130MW에 대해 30,121.2 → 30,035.0MW로 바뀌어 절대오차가 8.8 → 95.0MW로 늘었습니다. 직전 실측까지만 허용하는 단순 수정은 29,613.3MW까지 낮아졌습니다. 실측·대상 변화량 기반 상승 여유로 이 부작용 대부분을 줄였으며, 특정 날짜의 기존 예측값을 보존하는 예외는 넣지 않았습니다.

9월 10일 15:43 발행의 16시 대상은 34,088.9 → 33,400MW로 바뀝니다(실측 33,250MW). 17:36 발행의 18시 대상은 33,948.5 → 33,248.5MW입니다(실측 32,740MW). 여전히 오차가 남으므로 원천 모델의 높은 수요 편향 전체를 해결했다고 볼 수 없습니다.

## 테스트와 적용

외부 네트워크를 차단한 전체 테스트 **628개 통과**, 하한·상한·밴드 집중 테스트 126개 통과입니다. 실제 운영 config를 사용한 후단 상한 결합 fixture에서는 15시와 16시 모두 33,400MW가 되며, 기존 결과에서 무조건 700MW를 뺀 값이 아닙니다.

회귀 테스트는 낮아진 수요의 정체, 실제 상승, 약하거나 누락·불일치하는 과거 변화량, 관측 공백, 하락 여유, 복원 상한, 입력·관측 구간 불변성, p95/p99 이동 일관성을 확인합니다. 정책 fingerprint 테스트는 기존 무제한 과거 하한 이력을 구분합니다. 테스트 프로세스의 외부 네트워크를 차단하며 유료 API 호출, ETL 재실행, 학습은 필요하지 않습니다.

학습된 `v14-r2-source-robust-day-ahead` artifact와 가중치는 그대로입니다. q50 후처리 의미가 바뀌므로 `servingSemanticsVersion`을 **2**로 올립니다. 이전 정책 스냅샷을 새 밴드 보정 이력으로 섞지 않습니다. 호환 이력이 충분해질 때까지 native 밴드 정규화·상한 처리를 유지하며, 이번 수정이 밴드 축소나 실측 포함률 95%를 보장하지는 않습니다.

배포 후 일반 Intraday 실행으로 미관측 대상을 새 규칙으로 계산합니다. 개선을 보여주기 위해 이미 게시된 실측 구간 예측이나 과거 점수를 다시 쓰지 않습니다. 새 fingerprint에서 복원량·상승 여유, 밴드 순서, 사전 발행 오차를 확인합니다.

## 남은 작업

- 설계 확정 후 22:29 JST Pages를 별도로 확인하니 19~20시 실측 31,570 / 29,990MW가 추가됐습니다. 보관한 19:29 재계산에 최종 후보를 대입해도 복원 700MW는 유지되어 32,145.6 / 31,156.3MW이고, 오차 +575.6 / +1,166.3MW도 그대로입니다. 19시는 대상 구간 시작 후 갱신, 20시는 사전 예측입니다. 보정한 입력이 이미 실측 지지 하한보다 낮아, 과도한 과거 수준을 제한하는 것만으로 예상되는 저녁 하락까지 해결할 수 없다는 증거입니다. 위 표의 개선 대상으로 포함하지 않았습니다.
- 오후 상한에는 대상 시간, 리드, 마지막 실측 시간의 별도 경계가 있습니다. 17:36 실행은 `lastObservedHour=16`이 설정 상한 15를 넘었고, 평탄한 실측 기울기여서 저녁 하락 조건에도 해당하지 않았습니다. 하방 제어가 추가로 해제된 이유입니다. 시간·리드를 늘리면 경계가 이동할 뿐 안전한 인계가 입증되는 것은 아니므로 이번 수정에는 포함하지 않았습니다.
- 오전 원천 모델의 기상·lag 민감도와 자정 초기 보정은 별도 제거 실험 대상입니다. 오늘 오차 전체를 이 하한 문제로 설명하지 않습니다.
- 후속 검증은 발행 시점에 이용 가능했던 입력으로 실제 상승 재개, 일시적인 점심 dip, 시원한 평일, 주말을 함께 다뤄야 합니다. 해당 시간 진단과 전체 일간·장기 회귀 검증을 병행합니다.
