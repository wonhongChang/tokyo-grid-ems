# 2026-09-04 Rolling Conformal Target 예측 밴드

언어: [English](../../en/model-improvements/model-improvement-2026-09-04-rolling-conformal-target-interval.md) / [日本語](../../ja/model-improvements/model-improvement-2026-09-04-rolling-conformal-target-interval.md)

## 문제

기존 rolling conformal은 밴드의 **최소 폭만 올리는 floor**였다. native quantile 폭이 이미 과대해도 줄일 수 없어, v14-r2 고정 홀드아웃 12일에서 P95 커버리지는 100%였지만 평균 반폭은 3,700.2MW였고 대부분이 3,750MW 상한에 붙었다. 이는 안정적인 불확실성 표현이라기보다 구간별 위험 구분이 사라진 상태였다.

## 변경

서빙 전용 P95 target 정책을 모델 artifact 밖에 추가했다.

1. 타깃 날짜 이전의 확정 데이터만 사용한다.
2. 최근 28일 중 같은 영업 레짐의 시간대별 절대오차 q95를 계산한다.
3. 최근 10일 전체 레짐의 시간대별 q95를 드리프트 안전망으로 계산한다.
4. 두 값 중 큰 값에 1.05 안전계수를 곱하고 3,750MW로 제한한다.
5. 새 target이 모든 시간대에 준비된 경우에만 q50 중심의 대칭 P95 폭으로 교체한다.
6. 표본이 부족하거나 파일이 불완전하면 기존 floor/native band로 fail closed한다.

설정은 `served_interval_calibration`에 분리했다. 이 계층은 훈련된 quantile estimator를 바꾸지 않으므로 LightGBM artifact fingerprint와 q50 모델 계약을 변경하지 않는다.

## 검증

모든 결과는 타깃 날짜를 학습 창에서 제외한 인과적 walk-forward 재현이다.

| 구간 | 기존 P95 커버리지 | 새 커버리지 | 기존 평균 반폭 | 새 평균 반폭 | 변화 |
|---|---:|---:|---:|---:|---:|
| v14-r2 고정 origin 12일 | 100.00% | 98.61% | 3,700.2MW | 2,455.5MW | 33.6% 축소 |
| 최근 28일 | 97.92% | 97.17% | 3,200.0MW | 2,675.6MW | 16.4% 축소 |
| 최근 84일 | 95.19% | 96.08% | 2,373.0MW | 2,139.6MW | 9.8% 축소 |
| 2026-05-20~09-02 106일 | 94.73% | 96.78% | 2,168.6MW | 2,199.0MW | 1.4% 확대 |

84일 기준 영업일 95.83%, 비영업일 96.63%였고 시간대별 최저는 새벽 94.44%였다. 낮과 늦은 오후처럼 기존 커버리지가 부족한 구간은 넓히고, 새벽과 저녁처럼 과대했던 구간은 줄였다. 따라서 목표는 일괄적인 축소가 아니라 P95 의미 복원이다.

## 운영 추적

각 forecast JSON의 `intervalCalibration.servedTarget`에 다음을 기록한다.

- 같은 레짐 및 최근 전체 레짐의 표본 기간
- 시간대별 표본 수와 q95 폭
- 안전계수와 최종 target 폭
- target 적용 가능 여부 및 fallback 상태

## 제한

- P95는 장기 주변부 커버리지 목표이며 모든 날짜가 95%를 만족한다는 뜻은 아니다. 급격한 레짐 전환일은 여전히 낮은 일별 커버리지가 발생할 수 있다.
- P99는 기존과 동일하게 최종 P95 반폭을 한 번 더 확장한다.
- 이 변경은 q50 정확도를 개선하지 않는다. v15 q50 후보는 별도 점검에서 승격을 거부했다.
