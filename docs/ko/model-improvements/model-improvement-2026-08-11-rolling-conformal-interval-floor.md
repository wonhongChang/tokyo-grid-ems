# Rolling Conformal 예측 밴드 최소 폭 보정

언어: [English](../../en/model-improvements/model-improvement-2026-08-11-rolling-conformal-interval-floor.md) / [日本語](../../ja/model-improvements/model-improvement-2026-08-11-rolling-conformal-interval-floor.md)

## 문제

독립적으로 학습한 q025/q975 tail은 기상 레짐 전환 뒤 불안정해질 수 있다. 기존 3,000MW 반폭 상한은 극단적인 밴드가 UI를 지배하는 현상은 막지만, 고정 상한만으로 undercoverage를 해결하지는 못한다. 최근 확정 28일 운영 replay에서 p95 coverage는 전체 93.8%, 비영업일 90.7%, 오전 89.3%였다.

## 변경

공개 예측 구간에 누수 없는 rolling conformal 최소 폭을 적용한다. 각 예측 대상일마다 파이프라인은 다음 순서로 계산한다.

1. 대상일 이전에 ETL 완료로 표시된 최근 28일을 선택한다.
2. 24시간이 완전하지 않은 파일과 `tepco_forecast_fallback` 값을 제외한다.
3. 대상일과 같은 영업일 또는 비영업일 레짐만 남긴다.
4. 실제값과 당시 공개 q50의 절대오차를 새벽, 오전, 낮, 늦은 오후, 저녁으로 나눈다.
5. 표본이 24개 이상인 시간대에 유한표본 95% 상위 분위수를 계산한다.
6. 그 값을 대칭적인 p95 최소 반폭으로만 적용한다.

기존 밴드를 좁히지 않으며 기존 3,000MW 상한도 넘지 않는다. 대상일 실측과 TEPCO 예측은 calibration 입력으로 사용하지 않는다.

## Walk-Forward Replay

최근 확정 28일 각각에 대해 해당 날짜 이전 데이터만 사용하는 인과적 방식으로 검증했다.

| 구간 | 기존 coverage | 후보 coverage |
|---|---:|---:|
| 전체 | 93.8% | 95.8% |
| 영업일 | 95.2% | 95.8% |
| 비영업일 | 90.7% | 95.8% |
| 새벽 | 97.0% | 97.0% |
| 오전 | 89.3% | 94.3% |
| 낮 | 91.4% | 95.7% |
| 늦은 오후 | 89.3% | 90.5% |
| 저녁 | 99.3% | 99.3% |

평균 p95 반폭은 2,349.3MW에서 2,493.9MW로 144.6MW 증가했고, 최대값은 3,000MW로 유지됐다.

## 2026-08-11 확인

비영업일 profile에는 9일이 기여했다. 최소 반폭은 새벽 1,561.5MW, 오전 2,949.6MW, 낮 2,230.6MW, 늦은 오후 3,000MW, 저녁 1,870MW다. 07시 공개 하한은 24,613.6MW에서 24,186.3MW로 이동해 24,350MW 실측을 포함한다. 이미 충분히 넓은 시간은 바뀌지 않는다.

## 추적성과 실패 처리

forecast JSON의 `intervalCalibration`에 계산 방식, 대상 레짐, 이력 구간, 기여 일수, 시간대별 표본 수와 최소 폭을 기록한다. state 누락, 불완전 이력, 표본 24개 미만이면 해당 시간대는 밴드를 바꾸지 않고 fail-closed 처리한다.

## 잔여 위험

늦은 오후 coverage는 3,000MW 상한에서도 90.5%에 머문다. 이는 주로 중앙 예측선과 shape drift 문제이므로 더 넓은 밴드로 감추지 않는다. 저녁의 overcoverage도 남는다. 이번 정책은 최소 폭만 보강하므로, 별도의 양방향 calibration 실험이 안전성을 입증하기 전에는 기존 밴드를 좁히지 않는다.

## 검증

- 유한표본 rank, 대상일 누수, 확정 출처, 표본 부족, JSON 근거, 3,000MW 상한 테스트를 추가했다.
- 전체 테스트: `500 passed`.
- v11 Champion, q50, raw quantile 모델, intraday 보정, TEPCO 독립 모델링 원칙은 변경하지 않았다.
