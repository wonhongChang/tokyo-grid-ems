## 3. 예상 사용률의 출처

개선 전 `web/src/App.tsx`의 `peakUsageMetric()`은 실측 사용률이 있으면 이를 쓰고, 없는 시간에는 **우리 모델 수요 / TEPCO 공급력**으로 계산했습니다. 최대값에 따라 카드가 실측 또는 모델 예상으로 바뀌었지만, 바로 옆 수요 카드는 TEPCO 최대 예측이었습니다.

9/17 배포 화면 점검 당시 17시 예상 사용률 89.7%는 모델 34738.8MW / 공급력 38710MW였습니다. 같은 시각 TEPCO 예측 33820MW로 계산하면 약 87.4%입니다. 두 값의 차이는 계산 오류가 아니라 분자 출처의 차이입니다.

권장 표시 계약:

- `최대 실측 사용률`: 유효 실측만 사용. 대체 예측값을 실측으로 섞지 않습니다.
- `TEPCO 예상 최대 사용률`: TEPCO 예측 / 해당 시간 공급력. 기본 예상 지표로 사용합니다.
- `모델 예상 최대 사용률`: 모델 예측 / 해당 시간 공급력. 별도 보조 지표 또는 펼침 영역에 둡니다.
- 공급력에는 어떤 사용률 피크 시각에 대응하는 값인지 명시합니다. 서로 다른 시간의 수요 피크와 공급력을 합쳐 계산하지 않습니다.
- 공급력 0·결측, TEPCO 예측 결측은 `-` 등 결측 상태로 표시합니다. 다른 출처로 조용히 바꾸지 않습니다.

세 언어에서 출처가 보이도록 하고, 92%·97% 경고 기준이나 실제 모델 보정 로직은 건드리지 않습니다. 검증은 출처 선택, 결측, 동률, 시간 매칭, 반올림 경계를 포함합니다.

## 4. 검증 탭의 비교 계약

현재 그래프는 `metrics/forecast_accuracy.json`을 읽습니다. 해당 JSON은 다음을 명시합니다.

- `type: latest_published_value_reference`
- `tepcoSourceMayRevisePastValues: true`
- `formalParityEligible: false`

따라서 현재 `운영 판단: TEPCO`는 엄밀한 동일 조건 성능 판정으로 오해될 수 있습니다. 문구를 `게시값 기준 오차 비교`로 한정하고, TEPCO 과거 예측 수정 가능성을 짧게 설명해야 합니다.

이미 생성되는 `metrics/forecast_vintage_accuracy.json`을 별도 보기로 연결합니다. 이 보고서는 같은 `capturedAt`에서 수집한 예측을 양의 lead로 평가합니다. 원본 `issuedAt`은 없으므로 **동일 발표 시각**이라고 부르지 않습니다.

권장 구조는 `사전 예측 비교` / `최신 게시값 참고` 두 보기입니다. 사전 비교에는 0~2 / 2~4 / 4~8 / 8~24시간 구간, 표본 수, 평가 기간, 모델·정책 범위, 표본 부족 상태를 표시합니다. 서로 다른 lead를 한 점수에 무조건 합치거나, 표본 부족일 때 참고 비교를 정식 평가처럼 대체하지 않습니다.

## 5. MAE 격차의 해석과 차트 개선

[게시값 비교 데이터](https://wonhongchang.github.io/tokyo-grid-ems/metrics/forecast_accuracy.json) 기준입니다. 최신 행은 이후 갱신될 수 있습니다.

| 범위 | 모델 MAE | TEPCO MAE | 절대 차이 | 모델 / TEPCO | 모델 / TEPCO WAPE |
|---|---:|---:|---:|---:|---:|
| 8/19~9/17, 713시간 | 605.9MW | 342.2MW | +263.7MW | 약 1.77배 | 1.86% / 1.05% |
| 최근 완료 7일, 9/10~16, 168시간 | 약 502.0MW | 약 232.7MW | 약 +269.3MW | 약 2.16배 | 별도 합산하지 않음 |
| 9/15 확정, 24시간 | 673.2MW | 179.6MW | +493.6MW | 약 3.75배 | 2.06% / 0.55% |
| 9/16 확정, 24시간 | 498.1MW | 153.8MW | +344.3MW | 약 3.24배 | 1.65% / 0.51% |
| 9/17 잠정, 00~16시 | 346.5MW | 237.6MW | +108.9MW | 약 1.46배 | 1.19% / 0.81% |

7일 MAE는 공개된 일별 MAE를 시간 수로 가중한 근삿값입니다. 30일과 그래프의 최근 14일, 표의 최근 10일은 서로 다른 범위이므로 제목에 기간을 명시해야 합니다.

**판단:** 수요 규모 대비 평균 절대 오차가 1~2%대라는 것과 TEPCO 수준에 도달했다는 것은 다릅니다. 최근 며칠의 상대 격차는 실제로 크며, 목표 대비 충분하다고 말하기 어렵습니다. 다만 이 게시값 비교는 TEPCO의 사후 수정 가능성 때문에 정확한 사전 경쟁력 판정에는 사용할 수 없습니다. 과거 스냅샷 비교에서도 격차가 확인됐으므로 전부 그래프나 비교 방식 탓으로 돌려서도 안 됩니다.

표시 개선안:

1. 같은 축·0 기준선·색상을 유지합니다. 차이가 덜 보이도록 축 범위를 인위적으로 늘리거나 이중 축을 쓰지 않습니다.
2. MAE / WAPE 지표 전환을 제공합니다. WAPE는 동일 표본의 절대오차 합 / 실측 합이며 일별 비율을 단순 평균하지 않습니다.
3. 툴팁에 모델·TEPCO MAE, 절대 차이, 양측 WAPE, 표본 수와 `집계 중` 상태를 함께 표시합니다. 배수는 보조 정보로만 사용하고 0 분모는 계산하지 않습니다.
4. 단위는 정확합니다. **1万kW = 10MW**, 따라서 50万kW는 약 500MW입니다. 현재 전력 포맷터는 한국어·일본어 정수, 영어 GW 소수 한 자리로 반올림하므로 정밀 툴팁에 원래 MW 값도 제공합니다.
5. WAPE 1.86%를 `정확도 98.14%`로 바꾸지 않습니다. 평균 오차와 최대 오차, 편향, 시간별 형상 오차도 구분합니다.
