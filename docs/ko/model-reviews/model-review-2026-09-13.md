## 판정

토요일의 전체 게시 예측은 비교적 안정적이었지만, **06~07시 후처리 과대예측과 09~14시 과소예측은 개선 대상**이다. 일요일 초기 점검은 06시까지, 마감 추가 확인은 12시까지의 잠정 실측을 사용했다. 오늘 오후·저녁 예측이 맞는지는 아직 알 수 없다.

전날 영업유형이 다르면 lag24 기울기를 일괄 제외하는 후보는 이전 토요일을 악화시켜 **기각했다**. 이후 가드 이전의 실제 관측이 낮은 예측 수준을 뒷받침할 때만 제외하는 조건부 안을 재생하고 구현했다. 학습 artifact는 유지하며 서빙 가드의 근거 선택만 바꾼다. AI 리포트의 근거 연결 오류도 수정했다. 원형 모델 승격이나 예측 개선 완료와는 구분한다.

## 1. 근거와 운영 상태

- Pages 07:48:34 JST 게시본과 data commit `2c5fd2b98b7c64230ae28857e4c545be3948c325`의 status 및 9월 11~13일 actual/forecast JSON 내용이 일치했다. 분석용 사본과 SHA256 manifest를 별도로 보존했다.
- 07:30 ETL은 07:45에 완료됐다. 확정 CSV 범위는 9월 12일까지이며 실패일은 없다. ETL 재실행이나 별도 데이터 push는 하지 않았다.
- 모델은 `v14-r2-source-robust-day-ahead`, artifact `c2914b699dc306c61c6eb8f777d99fdebf1f7336dbf83bd01d851156e8b0cdd3`다.
- `tepco_forecast_fallback`은 평가 실측과 잔차에서 제외한다. 확정 CSV와 수집 당시 잠정 실측이 달라질 수 있으므로, 오차 평가는 확정값, 보정 재생은 해당 실행이 알았던 값을 사용했다.
- TEPCO 비교는 같은 수집 snapshot에서 양측 값이 있는 행만 사용했다. 시간별 최소 양수 lead 하나를 골랐으며, TEPCO 자체의 최초 발표 시점까지 같다는 뜻은 아니다.

## 4. 후보 비교와 조건부 수정

후보는 영업유형 mismatch가 있으면 아침 shape floor에서 lag24 기울기를 제외하고 최근 같은 영업유형 기울기만 사용한다. 날짜별 수동 보정, 새 상한값, TEPCO 예측 입력은 없다.

먼저 저장된 8월 14일~9월 10일의 D0/D-1 origin 각 672시간을 재사용했다. D-1 결과는 변하지 않았지만 D0의 8월 22일·29일·9월 5일 아침 일부는 악화됐다. 단순 최신 재학습이나 specialist 비중 실험은 이전에 기각되어 반복하지 않았다.

추가로 네 토요일과 오늘의 오전 실행 51개를 과거 Git cache 및 당시 실제 관측으로 재생했다. 기록된 raw/상위 level/analog 단계는 고정하고, timeband/midday/shape와 Intraday를 함께 계산했다. 기준선이 기록된 pre/post와 반올림 허용치 내 일치한 48개만 아래 집계에 사용했다. 세 실행은 이후 제어 정책 차이가 있어 제외했다. 합성 밴드 경계를 사용한 q50 검증이며 밴드 재생이나 전체 Champion 승격 검증이 아니다.

### 조건부 안의 추가 검증

최종 구현은 첫 가드 타깃 이전의 연속 두 실측이 같은 시간의 가드 전 예측보다 기존 slack 250MW 이상 높지 않을 때만 동유형 기울기를 우선한다. 관측 부족, 실제 수준 부족, 동유형 기울기 결측이면 기존 동작을 유지한다. 06시 이후의 실측은 06~07시 가드 근거에 사용하지 않는다.

같은 재생 표본에서 조건부 안의 MAE는 08-22 968.9, 08-29 1,020.9, 09-05 463.4, 09-12 404.3, 09-13 296.9MW였다. 이전 토요일과 오늘은 불변이고 9월 12일만 개선됐다. 저장된 D0/D-1 각 672개 origin도 불변이다. 단, 9월 12일 08시 오차는 일부 커졌으므로 모든 시간의 개선으로 표현하지 않는다. [구현 계약·검증·롤백](../model-improvements/model-improvement-2026-09-13-observed-weekend-shape-support.md)에 상세를 남겼다.

## 5. 밴드와 AI 리포트

토요일 게시 P95 평균 전체 폭은 4,620.5MW, 24/24 포함이다. 보존 snapshot의 시작 전 0~2시간은 20표본, 평균 폭 4,924.0MW, 포함률 100%다. TEPCO ledger와 보존 개수가 달라 표본 수가 다르다. 넓은 밴드가 하루 실측을 포함한 것은 95% 확률 보정의 장기 검증이 아니다.

새 서빙 fingerprint의 호환 이력이 부족하여 `insufficient_history`와 native band 유지가 정상적으로 표시됐다. 최소 4일·24표본 요건을 낮추거나 다른 정책의 잔차를 섞지 않는다. 이번 조건부 설정을 배포하면 fingerprint가 다시 달라지므로 배포일부터 호환 이력 축적을 다시 확인해야 한다. 밴드 보정 활성 날짜를 미리 확정하지 않는다.

9월 12일 AI 리포트는 분석·현지화 모두 `gpt-4o-mini`, `localizationStatus=ok`였다. 그러나 17시의 실제 게시 오차는 -4.9MW인데 사후 재계산과의 863.7MW 차이만으로 저녁 모델 cap 후보를 생성했다. 추천의 `event.freeze_gap_h17`은 실제 통합 가설 ID와도 달랐다. 15시도 freeze 차이로 점심 피처 후보가 생성됐다.

이 결함을 수정했다. `published_recalculated_gap` 이벤트는 모델 튜닝 ticket을 만들지 않으며, 저장된 factPacket도 같은 검사를 거친다. ticket은 최종 보고서에 남은 실제 가설 ID에 연결된다. 실제 수요 오차 이벤트와 freeze 설명 자체는 유지한다. OpenAI 모델/API 설정은 바꾸지 않았고 유료 재생성·기존 게시 리포트 덮어쓰기는 하지 않았다. 이는 근거 연결 수정이지 AI 해설 품질 전체가 검증됐다는 뜻은 아니다.

### 일요일 추가 확인: 15:42 JST

마감 시 Pages의 13:32:34 게시본과 data commit `2502fbe3f56a236bd8ec33dfe37cb50cbbd48a8f`의 status/actual/forecast가 일치했다. 실측은 00~12시 13개이며 게시 MAE 265.7MW, WAPE 1.13%, Bias +51.7MW, 최대 절대오차 507.2MW다. 같은 수집본의 시작 전 0~2시간 비교는 12개 타깃에서 모델 MAE 372.0MW, TEPCO 320.0MW다. 위 오전 표와는 표본 시점이 달라 별도 기록한다.

오늘 11시 게시 오차는 -507.2MW, 12시는 -489.8MW였다. 11:36 실행에서 12시 raw 27,034.2MW가 실측 27,840MW보다 이미 805.8MW 낮았고, 잔차가 71.2MW를 추가로 내렸다. 평일 점심 가드가 일요일에 작동한 문제가 아니다. 오늘 12시 이후는 아직 평가하지 않는다. P95는 13/13 포함, 평균 전체 폭 4,329.8MW로 여전히 넓다.

## 6. 다음 작업

1. 일요일 확정 CSV가 들어온 9월 14일 ETL 후, 오늘 낮·저녁과 토요일 잔여 오차를 함께 확인한다. 그때까지 기다려야만 원인 분석을 할 수 있다는 뜻은 아니다.
2. 조건부 아침 floor를 배포한 뒤 다음 주말의 실제 높은 수요와 08~11시 잔차 부작용을 함께 점검한다. 이번 재생 피처를 재사용하며 일별 상수 조정을 반복하지 않는다.
3. D0 09~14시 raw 과소예측과 D-1 전용 모델의 레짐별 편향은 별도 실험이다. 한쪽 개선을 다른 lead의 개선으로 간주하지 않는다.
4. 새 밴드는 같은 정책·양수 lead 표본으로 점검한다. q50 개선 여부와 폭·포함률 판단을 분리한다.

이번 변경은 조건부 아침 가드, AI ticket 근거 검증, 테스트와 문서다. 점검 과정에서 원형 모델 교체, 자동 실행, 배포 데이터 갱신은 하지 않았다. 소스 push와 실제 배포 상태는 별도로 확인한다.
