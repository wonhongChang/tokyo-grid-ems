# 2026-09-15 고온 이후 기온 하락일 점검

언어: [English](../../en/model-reviews/model-review-2026-09-15.md) / [日本語](../../ja/model-reviews/model-review-2026-09-15.md)

## 판정

**오늘 오후 과대예측은 실제로 발생했다. TEPCO 예측이 이상했던 것이 아니다.** 어제는 더워진 영업일 복귀의 과소예측, 오늘은 기온이 내려간 연속 영업일의 과대예측이다. 한쪽 날짜만 보고 예측 전체를 올리거나 내리는 조치는 적절하지 않다.

ETL과 배포는 정상이다. 저장된 입력·모형으로 후보를 검증했지만 **이번에 채택한 모델/가드 변경은 없다.** 관측 지지 시 오전 가드 해제, 절반 완화, feature-view 한도 일괄 확대를 운영에 적용하지 않았다. 훈련 가중치, 설정, 게시 예측선, AI 리포트도 변경하지 않았다. 유료 API 호출과 재학습은 하지 않았다.

## 1. 증거 범위

- 20:15 JST 수집본을 data commit `98056e6ca2d41fa2b4e7df5e07732dd4b41d4f7b`에 고정했다. Pages status와 9월 14~15일 actual/forecast JSON 내용이 일치했다. 오늘 최신 forecast 생성 시각은 19:30:54 JST다.
- 9월 14일은 확정 24시간, 15일은 잠정 00~18시의 19시간이다. 시간 `15`는 15:00~16:00 수요이며, 없는 19시 이후 실측은 평가하지 않는다.
- 오늘 ETL은 08:44~09:00에 완료했고 14일 확정 CSV와 AI 리포트가 게시됐다. Champion은 `v14-r2-source-robust-day-ahead`, artifact `c2914b699dc306c61c6eb8f777d99fdebf1f7336dbf83bd01d851156e8b0cdd3`, 학습 cutoff는 2026-08-01이다.
- 정책 fingerprint는 `d788cbbcd3d956a5344bf0ce2fb7d960da425390c148516acfbd40b8f9b94ee4`다. 13일에 수정한 토요일 floor는 두 평일의 원형 예측을 바꾼 원인이 아니다.
- 사전 예측 비교는 같은 수집 snapshot의 양측 값을 사용한다. 각 타깃의 최소 양수 lead를 구간별로 선택하며, TEPCO 자체의 최초 발표 시각까지 일치한다는 뜻은 아니다. 대체 실측은 제외한다.
- 아침 수집본과 저녁 수집본은 별도로 보존했다. 사후 기상 대입 실험은 아래에서 명시적으로 분리하며, 후보 성능이나 배포 예측으로 집계하지 않는다.

## 3. 오늘 원인 분리

### 오전 기상 갱신과 오후 원형 수준

09:01 당시 12·13·15시 원형 예측은 각각 41,056.0·42,295.3·42,372.1MW였다. 후처리 직전과 같으며 Intraday는 약 +50~70MW만 추가했다. 아침의 큰 낮 격차는 잔차 보정 폭주가 아니라 원형 단계에서 시작됐다.

반면 08시는 06:26 실행의 raw 33,788.6MW가 실측 33,900MW에 가까웠지만, ETL 때 최신 기상으로 재계산된 raw가 31,930.3MW로 낮아졌다. 모형 버전 변경 없이도 기상 입력이 바뀌어 예측이 달라진 사례다. ETL 실패와는 다르다.

### 기상 사후 대입: 무엇을 설명하고 무엇을 설명하지 못하는가

아침 07~09시 습도 99%는 AMeDAS 관측과 맞았다. 습도 자체가 잘못 들어왔다고 단정할 수 없다. 낮 예보 기온 28°C에 대해 실측은 12시 25.7°C, 13시 26.9°C, 14시 26.4°C였다. 높은 기온 예보와 습도가 결합해 아침 입력의 체감온도가 약 35°C로 계산됐다.

동일한 09:01 수요 입력과 가중치를 유지하고, **나중에 확보한 AMeDAS 기상만 대입한 사후 진단**을 수행했다. 수요 실측은 모델 입력에 추가하지 않았다. 아래 결과는 당시 만들 수 있었던 예측도, 승격용 검증 성적도 아니다. 17시는 보존 cache의 기상 출처가 관측이 아니므로 제외했다.

### 점심과 밴드

오늘 11→12시 실제 감소는 -730MW였다. 아침 Midday guard는 전날 -130MW, 최근 동유형 평균 -483.75MW가 모두 -500MW 발동 기준에 못 미쳐 작동하지 않았다. 어제의 실제 감소는 확정 기준 -130MW에 불과했다. 두 날을 함께 보면 평일 고정 dip 강제나 기준만 낮추는 변경은 아직 정당화되지 않는다.

표시 P95 전폭은 관측 19시간 평균 5,836.0MW이고 19/19가 포함된다. 최신 calibration은 `insufficient_history`, 선택 표본 12개, 최소 표본 24개·최소 4일이다. 정책 불일치 제외는 309개다. 넓은 기본 밴드의 포함률을 중앙 예측 성공으로 해석하지 않는다.

## 4. 실제 수행한 후보 검증

### A. Feature-view 변경 한도 확대: 일괄 적용 기각

현재 500MW 한도를 1,500MW 및 무제한으로 비교했다. 기존 artifact와 8월 14일~9월 10일의 D0/D-1 입력, 14일 네 실행·15일 아침 한 실행을 재사용했다. **61개 기준 실행의 raw가 모두 0.2MW 이내 재현**됐다. 재학습과 전체 Intraday 재생은 포함하지 않는다.

- D0 시작 전 타깃 639개의 raw MAE: 1,385.9→1,377.5MW. D-1 672개는 변경 없음.
- 오늘 09:01 당시 미래였고 이후 실측이 있는 10~18시 9개 raw MAE: 2,813.0→2,448.3MW. 여전히 오차가 크다.
- 8월 24일 D0 MAE는 644.0→731.4MW로 악화됐고 17시 절대오차가 534.9MW 커졌다. 9월 9일 13시도 530.1MW 악화됐다.
- 어제 네 실행의 미래 행을 합친 raw MAE도 870.0→878.8MW로 악화됐다. 이 집계는 같은 타깃의 여러 발표를 포함하므로 일간 게시 MAE가 아니다.

오늘 일부 개선만으로 안전장치 한도를 일괄 확대하지 않는다.

### B. 관측 지지 시 오전 slope 억제 완화: 단독 적용 기각

보존된 327실행에서 08~10시 shape 감소 50행을 확인했다. 연속 3개 관측의 상승 및 예측 수준 지지 조건을 만족한 두 날짜의 22실행을 원래 raw/상위 단계를 고정하고 **shape와 잔차 보정까지 함께** 재생했다. 기준 pre/post는 22/22 실행에서 반올림 허용치 내 재현됐다. 합성 대칭 밴드를 사용한 q50 실험이며 밴드 검증은 아니다.

완전 해제와 50% 완화 모두 시험했다. 두 경우 모두 기존 단발 peak 제어와 구분하고, 당시에 알려진 실제 관측만 지지 근거로 사용했다.

## 5. 다음 작업의 명확한 범위

1. **기상 vintage에 강한 원형 모델 후보:** 관측과 예보에서 파생기온 정의·오차 분포가 어떻게 다른지 확인하고, 실제 확보된 예보 vintage 또는 훈련 구간에서만 추정한 기상 오차를 사용한 강건성 학습을 검증한다. 실측 기상을 넣은 사후 실험을 성능으로 보고하지 않는다.
2. **잔차 기준선과 시간별 수준 적응을 함께 검증:** 오전 shape를 바꾼 후보의 11~13시 부작용, 15시의 관측 기상 대입 후 남는 오차, 낮 잔차의 저녁 전파를 동일 실행 순서로 검사한다. 공통 잔차 cap 확대나 시간별 강제 리프팅으로 대체하지 않는다.
3. **명확한 평가 범위:** 더워진 영업일 복귀, 이어지는 기온 하락일, 정상 평일, 주말을 모두 포함한다. 전체 24시간과 lead별 MAE/WAPE, bias, 최대오차, 형상 오차, 밴드 폭·포함률을 확인한다. 후보의 개선 폭과 악화 사례를 함께 공개한다.
4. **다음 작업은 9월 16일 ETL·푸시 완료 후:** 오늘 잠정 실적을 확정하고 미관측 19~23시를 추가한 뒤, 위 원형 입력 강건성·잔차 결합 후보의 구현과 검증을 이어간다. 확정 자료 보완은 후보 실험을 20일까지 미루는 조건이 아니다.
5. **9월 20일 일요일 ETL 후 종합 점검:** 14~18일 평일과 19일 토요일 확정 실적을 함께 평가한다. 금요일→토요일 전환 가드, 평일 개선 후보의 주말 부작용, lead별 중앙선·밴드 성능을 종합 확인한다. 다음 평일 개선 작업과 구분하며, 장시간 전면 재학습이나 모델 승격을 날짜만으로 자동 결정하지 않는다.

오늘의 결론은 정상 모델이라는 판정이 아니라 **문제가 확인됐고, 간단한 두 종류의 변경은 해결책으로 통과하지 못했다**는 것이다. 다음 작업은 가드를 더 쌓는 대신 위 원형 입력 강건성과 잔차 결합을 대상으로 한다. 모델 개선 로그는 실제 채택된 구현이 없으므로 추가하지 않는다.
