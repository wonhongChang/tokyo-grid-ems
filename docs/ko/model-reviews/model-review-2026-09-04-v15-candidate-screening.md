판정: **v15 q50 승격 거부, v14-r2 유지**

## 결론

최신 데이터를 추가해 같은 구조로 재학습한 후보부터 lag 가중치, 기상 입력 view, 학습 기간, origin 전용 모델과 residual stacking까지 순차적으로 검증했지만, 개발 구간과 고정 홀드아웃을 함께 통과한 후보는 없었다. 특정 홀드아웃에서만 좋아 보인 결과는 개발 구간 열화, 구간 회귀 또는 넓은 bootstrap 신뢰구간 때문에 거부했다.

이번 점검에서 모델 버전을 올리지 않은 것은 작업을 중단한 결과가 아니다. 동일한 고정 origin과 배포 artifact를 기준으로 후보를 탈락시킨 명시적 승격 결정이다. q50 서빙 동작은 바꾸지 않는다.

## 운영 결정

1. v14-r2 q50와 모델 artifact를 유지한다.
2. 특정 실패일을 겨냥한 시간대 cap이나 새 guard는 추가하지 않는다.
3. P0 운영 증거 수정으로 보존되는 D-1 origin을 계속 축적한다.
4. 다음 q50 Challenger는 단순 재학습이 아니라 forecast vintage 기상 lineage와 새로운 레짐 표현을 먼저 확보한 뒤 설계한다.
5. 예측 밴드는 q50와 분리된 서빙 보정 문제이므로 별도 검증을 통과한 rolling conformal target 정책만 적용한다.

## 남은 위험

- 고정 D-1 홀드아웃은 12일뿐이라 모델 구조 변경을 확정하기에는 짧다.
- D0와 D-1은 입력 가용성이 달라 하나의 후보가 두 origin에서 반대 결과를 낼 수 있다.
- 최신 TEPCO 값은 과거 값이 수정되므로 승격 gate로 사용하지 않았다.
- 실패 후보와 수치는 점검 기록으로 남기되, 실험용 artifact와 임시 데이터셋은 배포 저장소에 포함하지 않는다.
