# 예측 구성요소의 제한적 운영 전환

기존 모델 승격·Shadow·Prospective 계약은 소급 변경하지 않는다. 특정 버전의 D-1 중심선만 바꾸는 제안은, 모델 가중치 전체를 교체하는 제안과 별도 안건으로 판단한다. 대상은 D-1 중심선, 당일 적응, 기상 입력, 구간 폭, 발행 간 상태 전이 중 하나로 명시한다. 여러 개를 바꾸면 각각의 기여와 연결부를 검증한다.

1. 기존 운영 정책을 포함하여 같은 대상, 원래 발행 시점, 입력, 완료 실측으로 비교한다. 유지했을 때의 비용도 후보와 동일하게 공개한다.
2. 새 점수를 보기 전에 목적 지표, 비열등 허용 범위, 영향받는 취약 구간, 제외 사유, 제한 발행 범위와 복구 조건을 고정한다. 적은 날짜의 상관된 시간별 행을 독립 표본처럼 세지 않는다.
3. D-1이면 최초·서비스 의사결정 시각·마지막 발행을 따로 본다. 주목할 대상은 수정량 자체가 아니라 수정이 실측에 가까워졌는지와 최종 인계 예측의 오차다. D-1만 바뀌면 L5, 당일 closest를 해당 후보의 우월성 기준으로 쓰지 않는다. 다만 공유 상태·발행 동결·구간 이력에 부작용이 없는지는 검사한다.
4. 적용하지 못한 날을 빼서 좋아 보이게 하지 않는다. 사유가 명확한 기존 정책 fallback도 실제 운영처럼 후보의 점수에 넣는다. 재현하지 못한 자료는 별도 표시한다.
5. 기존 기간이 반복 사용된 경우 독립 검증이라고 쓰지 않는다. 범위 밖 위험은 제한 발행·동시 기준선·즉시 해제로 관리할 수 있는지, 아니면 새 근거가 꼭 필요한지 구분한다. 30일을 자동 요구하지 않는다.
6. 공개 중심선에는 정책 ID를 붙인다. 같은 발행의 기존 기준선은 명시적으로 구분해 대조 및 구간 폭 추정에만 사용한다. 이미 배포한 시간의 예측은 재작성하지 않는다.
7. 신규 정책의 활성화는 별도 승인이다. 준비 코드를 추가해도 설정과 지정 대상일이 없으면 어떤 공개 예측도 바뀌지 않는다. 위험이 확인되면 다음 발행부터 기존 경로로 복구한다. 과거 공개 이력과 실측은 보존한다.

예측 개선의 기준은 가설이나 후보 수가 아니라, 공개한 같은 시간대의 예측이 기준선보다 얼마나 정확하고 안정적인가이다.
